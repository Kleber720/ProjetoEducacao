# EduKation — Frontend

React 19 and Vite interface for Pomodoro sessions, Cornell notes, and saved notebooks.

See the [project README](../README.md) for features, architecture, database setup, API configuration, and the complete local workflow.

From this directory:

```sh
npm install
npm run dev
npm run lint
npm run build
```

The frontend expects the API at http://localhost:3000. Its address is configured in [src/services/api.js](src/services/api.js).
